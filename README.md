## 下单前必须知道的几个限制

**数字商品不退款。** 商店的购买说明写得很直白：数字商品一经交付就不退，除非当地法律另有规定或符合特定售后政策。买错版本、买多份、换了电脑想退，都不在退款范围内。买之前先用试用版跑一遍自己的文件。

**“买断”指的是当前这个大版本。** 一次性付费拿到的是永久使用权，同一大版本内的小更新跟着升。跨大版本（比如 11 升到 12）通常要另外付费，只有企业版订阅把大版本升级写进了权益。商店的购买说明里还写明，终身、一次性购买、永久更新这类说法都基于开发者提供的信息，后续更新和维护由开发者负责，商店不作担保。别把买断理解成以后所有版本都白拿。

**授权按用户数算，能不能装第二台电脑没写清楚。** 商品页按人头计价，但一份授权是否允许同一个人在自己的台式机和笔记本上各装一次，页面没有说明。经常在两台机器之间切换的人，下单前问一下客服。

**能查到的第三方评价很少。** Software Advice 上这款软件连一条用户评价都没有，独立测评也不多。这不代表软件差，它更像一款靠功能吃饭、不靠口碑传播的老工具，但你没法从别人的使用经验里预判问题，只能自己拿试用版验证。

**界面没有简体中文。** 官方列的界面语言有 11 种，英德法日俄都在里面，中文没有。日常操作靠图标和固定位置的按钮问题不大，但第一次配置那 100 多项打印设置时，英文界面对不熟悉的人有门槛。
